# Particle Life

Colored particles on a torus. Each species has an attraction or a repulsion toward every species, including itself, and that table does not have to match in both directions. Red can chase green while green flees red. The picture has no ending.

This is a first playable cut, now with a WebGPU path for the step and the picture. The matrix can be edited live. It does not yet search for an interesting random matrix, copy a custom matrix into the address, or drift the rules on its own. The CPU tests still describe the force law. A GPU run is not required to match them bit for bit.

## Decisions

- The world is the unit square with opposite edges joined. Distance is divided by the interaction radius. Inside 0.3 of that radius every pair repels. From there out to the radius the force is a tent: zero at both ends, peaking in the middle at the matrix value. Positive pulls toward the other particle. The matrix is row-major, and row `i` column `j` is how `i` feels about `j`.
- Neighbors come from a grid whose cells are at least one radius wide, so each particle checks the surrounding 3×3. When the radius is large enough that the world is under 3 cells across, it checks every cell once. Velocity is damped by a half-life (the Half-life control, in seconds) and then clamped so a wild matrix cannot fling particles out of the picture. One painted frame may run several fixed 1/60s slices, at realtime, up to 16. Leftover time past that cap is dropped.
- Positions and a generated matrix both come from the seed, on two streams, so changing the particle count does not reshuffle the rules. Opening the same address repeats those. A long run is not guaranteed to match bit for bit. Scatter places the particles again. Colors rolls a new set of hues. Rules fills every cell with a hundredth from −0.2 to 0.2, and half of those cells are exactly 0. A random preset uses that same fill. Mutate rerolls one cell with that same fill. Shuffle gives every color a different color's behavior. The particles and their hues stay put.
- The run never sets `done`. The sparkline is mean speed, shown in hundredths of a world-width per second, so a world that has settled sits near zero and a world that is still moving sits higher.
- When the browser has WebGPU, the neighbor search, the force step, and the dots run on the GPU. The same canvas the shell provides is the drawing surface. Positions stay on the GPU. The matrix still lives on the CPU, so Rules, Mutate, and Shuffle upload that small table. A sample of the speed comes back every few frames for the sparkline. Without WebGPU the original CPU step draws with Canvas 2D, and the run is capped at 8,000 particles. The default count is 50,000, and the slider runs from 1,000 to 50,000.
- Dots are soft and additive, on a square so the wrap matches on both axes. A dot that sits on an edge is also drawn on the opposite edge. Trails fade the previous frame instead of clearing it. The fade follows the frame's duration, so a faster monitor does not eat the trail. Reduced motion turns trails off. The grid at the bottom right is the matrix, and each number runs from −1 to 1. Drag a cell left to decrease it and right to increase it, or click and type. Green attracts, red repels, and the swatches are the species colors. Those hues are spaced evenly around the wheel. The first hue is rolled when the world starts, and Colors rolls a new one. Two species are opposite colors, and the pair is not part of the seed. Row is "this color feels", column is "about that color". The edit applies on the next slice and does not restart the particles.
- Radius, friction, force, trails, trail length, and dot size apply on the next slice. Changing the world or the particle count starts over. The species slider is always there. Raising it keeps the world and adds a last row and column of zeros. Lowering it removes that last row and column. Either way, particles are recolored so every species has the same count, and they stay where they are. Choosing a preset sets the slider to that preset's count. The address holds the params and the seed. It does not hold a matrix made with the grid, Rules, Mutate, or Shuffle.
