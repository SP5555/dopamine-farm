# Lozenge erosion

A hexagon tiled by three kinds of lozenges, shaded so it reads as a box of cubes. Removal takes one cube away at a time. Each removal rotates the three lozenges around that cube into the hole they leave. The box starts full. When it is empty, every lozenge turns 60° the other way around the hexagon center and takes the color of the face it lands on, which is the full box again. That turn lasts three times as long as one cube. Addition puts cubes back from whatever picture is on screen, then the full box turns back to empty. The empty picture is also the full picture rotated 180°, which is a different motion; the loop uses the 60° recolor.

## Decisions

- The state is a plane partition on an `n × n × n` cube. Size runs from 3 to 30 and defaults to 10. Heights fall away from the back corner `(0, 0)`. The viewer's front corner is `(n − 1, n − 1)`. A column can lose its top cube only when both forward neighbors are strictly shorter. A missing neighbor counts as 0. A column can gain a cube only when it is below `n` and both back neighbors are strictly taller.
- The picture is the boundary between solid and air, viewed along `(1, 1, 1)`. Cells behind the box are solid, and cells past the far faces are empty. That includes the floor and the two back walls, so an empty box reads as a room corner. Every state has `ab` horizontal lozenges, `bc` right-facing, and `ca` left-facing.
- The next cube is chosen from the heights on screen. Removal picks a column that can lose a cube. Addition picks a column that can gain one. Nothing records the whole order, so a new random stream can start at any picture. The seed stays inside the run: it is not shown, and it is not in the address. A new seed is rolled when Mode changes and when a finale commits. Size or Order still restarts the box.
- Switching Mode keeps the cubes on screen. A flip or a turn that has already started finishes in the direction it began. The next move follows the new mode, and a new seed is rolled for that pick. A switch between moves takes effect on the next one.
- One `step` commits one cube. The Animation menu has Rotate: `render(alpha)` turns that cube's three lozenges by `alpha × ±60°` and fades each tile toward the shade of the face it lands on. A removal turns clockwise. An addition turns the other way. After the last cube, the finale is one step with `span: 3`: every lozenge turns around the hexagon center the opposite way from that cube, and `alpha` runs from 0 to 1 across three speed ticks. Step advances the whole turn. Refill of the empty box is counter-clockwise (`ab → bc → ca → ab`). Emptying the full box is clockwise. At the end of that turn the picture is the start of the next pass, with a new seed. Several commits between paints snap, which is what turbo does. Reduced motion snaps the spin in that one step and still advances the pass. The menu is the place another motion can be added later.
- Random is uniform among the cubes that can move now. Nearest corner takes the legal cube closest to the front corner. Layer by layer takes the tallest legal cube first, then that same front-corner order. Diagonal sweep takes the smallest `(a−1−i) + (b−1−j)`, then the larger `i`. Ties break toward larger `i`, then larger `j`.
- The sparkline counts removable cubes during removal and addable cubes during addition. The frontier grows as the corner opens and shrinks as the box empties. Under random removal that frontier settles toward a smooth curve, the shape from random corner growth, so the trace is sculpted even though each pick is uniform. Each pass sets a new `series`, and switching mode changes the label, so the line starts over. The shell still keeps 600 samples. Progress is cubes moved this pass over `n³`, full while the box is empty in removal or full in addition, then back to 0 after the turn. The run is never done. The phase reads Removing, Adding, or Turning.
- Amber and Moss shade each face of a cube in one hue, lightest on top. RGB gives the three faces a soft red, a soft green, and a soft blue. Top faces paint last so they sit on the walls. Every lozenge has a thin outline.
- Faces of one orientation share a path, so a 30×30×30 box (2,700 lozenges, 27,000 steps) repaints once per frame. `step` changes one height. The turn at the end of a pass is one step that lasts three ticks, and committing it refills or empties the box.
- This sim's toolbar is Play, Step, and Speed. It opens at about 2 steps per second. Changing size keeps the speed the viewer set. Other sims keep the rest of the transport and the app default of 8/s.
